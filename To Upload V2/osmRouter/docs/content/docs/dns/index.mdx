osmRouter verifies that you own a domain by asking you to add an `A` record (and optionally a wildcard `A` record) pointing at our edge IP. The records are the same everywhere — the UI to add them is different at every registrar.

Pick your registrar:

- [Generic](/docs/dns/generic) — works for any registrar; use this if yours isn't listed.
- [GoDaddy](/docs/dns/godaddy)
- [Namecheap](/docs/dns/namecheap)
- [Cloudflare](/docs/dns/cloudflare)
- [Hostinger](/docs/dns/hostinger)
- [Squarespace](/docs/dns/squarespace)
- [Porkbun](/docs/dns/porkbun)
