The web dashboard at [osmrouter.com](https://osmrouter.com) is the control plane for your osmRouter account. Use it to add domains, see your devices, manage API keys, and watch live tunnel traffic.

The Mac app calls into the same control plane over HTTPS and WebSockets — anything you can do in the panel, you can do (often more conveniently) from the Mac app.
