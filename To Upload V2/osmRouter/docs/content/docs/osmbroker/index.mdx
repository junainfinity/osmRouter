title: osmBroker
description: "Turn Claude Code, Codex, Ollama, LM Studio, and 12 other terminal CLIs into a single OpenAI-compatible HTTP endpoint — running on your own Mac."

---

osmBroker is a separate Mac app that lives next to osmRouter. It speaks the OpenAI Chat Completions API on a local port, and routes each request to the right underlying CLI based on the requested model ID. Combine it with an osmRouter tunnel and you've got a public OpenAI-compatible URL backed by hardware you own.

Continue with [Overview](/docs/osmbroker/overview).
