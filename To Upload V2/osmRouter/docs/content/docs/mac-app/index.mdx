The osmRouter Mac app runs a small sidecar daemon (`osm-agent`) that maintains the tunnel to the cloud proxy. It exposes a SwiftUI panel for managing local services, domain bindings, and diagnostics.

Continue with [Install & sign-in](/docs/mac-app/install-and-signin).
